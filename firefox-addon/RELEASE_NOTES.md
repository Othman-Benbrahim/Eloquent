# Eloquent Local Assistant 0.1.0

Première version de développement de l’extension Firefox reliée à un serveur LanguageTool local.

Elle apporte la correction dans les champs `input`, `textarea` et `contenteditable`, des suggestions applicables en un clic, la détection automatique de la langue, le mode exigeant et la désactivation par site. Le texte reste sur la machine et l’extension refuse les serveurs non locaux.

Limite connue : le serveur LanguageTool doit déjà être lancé. L’intégration de démarrage automatique à Eloquent ainsi que les paquets macOS et Flatpak consolidés sont prévus pour les versions suivantes.
